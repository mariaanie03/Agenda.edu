# 📚 Agenda.edu

> **Sua rotina de estudos, mais simples.** Organize turmas, atividades, prazos e avaliações em um só lugar.



---

## 🚀 Sobre o Projeto

O **Agenda.edu** é um portal acadêmico web desenvolvido para simplificar a gestão escolar e o acompanhamento de rotinas de estudos. Inspirado nas dinâmicas de plataformas de ensino como o Google Classroom, o projeto traz um diferencial focado na visualização em **formato de cronograma**, facilitando o controle de prazos, entregas de trabalhos, conteúdos e avaliações tanto para professores quanto para alunos.

Atualmente, o projeto está hospedado e rodando via **Netlify**.

---

## ✨ Funcionalidades

### 👨‍🏫 Área do Docente
* **Criação e Gestão de Turmas:** Crie turmas informando nome, disciplina e ano letivo, com geração automática de código de acesso.
* **Cronograma e Atividades:** Publique conteúdos para estudar, links de apoio, materiais e atividades detalhadas com datas de início e fim.
* **Correção de Trabalhos:** Visualize os envios dos alunos, atribua notas (0 a 10) e envie feedbacks personalizados diretamente pela plataforma.

### 🎓 Área do Estudante
* **Ingresso em Turmas:** Entre facilmente nas turmas da sua escola utilizando o código de convite fornecido pelo professor.
* **Acompanhamento de Prazos:** Filtre atividades pendentes, concluídas ou visualize todo o cronograma organizado.
* **Envio de Tarefas:** Acesse materiais de apoio e envie o link dos trabalhos realizados com poucos cliques.

### ⚙️ Recursos Gerais
* **Autenticação e Perfis:** Suporte para diferentes perfis de acesso (Estudante e Docente com e-mail institucional `@ifpr.edu.br`, por exemplo).
* **Personalização de Tema:** Escolha entre diversos temas de cores personalizados para a interface do seu portal.
* **Banco de Dados em Tempo Real:** Dados gerenciados de forma segura e dinâmica utilizando **Supabase**.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

* **Frontend:** HTML5, CSS3 (com variáveis customizadas e design responsivo) e JavaScript moderno.
* **Backend / Banco de Dados:** [Supabase](https://supabase.com/) para autenticação e persistência de dados.
* **Hospedagem / Deploy:** [Netlify](https://https://agendaedu.netlify.app/).
